📊 E-commerce Sales Analysis -- Excel Module Assignment

📌 Project Overview

This project analyzes an e-commerce sales dataset using Microsoft Excel.
It focuses on data cleaning, analysis, and dashboard creation to
generate business insights.

🎯 Objectives

-   Clean and preprocess raw data
-   Perform descriptive and diagnostic analysis
-   Build KPIs
-   Create an interactive dashboard

🗂️ Dataset

File: Ecommerce_Sales_Dataset_MODULE 1-V1.xlsx

Includes: - Orders, Sales, Quantity - Product Categories - Customer &
Region details - Order Dates

🛠️ Tools

-   Microsoft Excel
    -   Pivot Tables & Charts
    -   Formulas (SUM, IF, XLOOKUP)
    -   Conditional Formatting
    -   Data Cleaning

🔍 Data Cleaning

-   Removed duplicates
-   Handled missing values
-   Standardized formats
-   Created calculated columns

📈 Analysis

Descriptive

-   Total Sales, Orders
-   Category & Region performance

Diagnostic

-   Top & low-performing products
-   Regional comparison

📊 Dashboard

-   Slicers (filters)
-   Monthly trends
-   Category-wise visuals
-   Regional insights

💡 Insights

-   Key categories drive revenue
-   Seasonal patterns exist
-   Some regions outperform others

🚀 Conclusion

Excel is effective for data analysis and visualization, helping generate
actionable business insights.
